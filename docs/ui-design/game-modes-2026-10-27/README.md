| 宽度 | 页面 | 结果 |
| --- | --- | --- |
| 1440 | 首页模式选择 | 四列模式卡，960px 内容宽，CTA 在首屏内；无横向溢出 |
| 768 | 首页模式选择 | 两列模式卡；顶部控件 44px；页面纵向滚动，无横向溢出 |

| 375 | 首页模式选择 | 两列模式卡，卡片最小宽 162px；无横向溢出 |
| 390 | 事件页 | 模式 chip、年龄、44px 音乐按钮同排；长剧本名截断但不溢出 |
| 390 | 回顾页 | 模式行、事实、节点、最终问题单列；无横向溢出 |

关键尺寸：

- 模式卡：1440 下 233×132；390 下 169×118；375 下 162×118。
- ForU 输入：移动端单列，输入框高度 44px；处境文本域 98px。
- 主题卡：移动端单列，125px 高。
- 剧本卡：移动端单列，96px 高。
- 顶部音乐开关：桌面 58×32；≤1023px 为 44px 高；事件页 compact 为 44×44。

## 交互验收

| 场景 | 观察 |
| --- | --- |
| 普通人生 | 0 岁开局；随机出身；童年继续；刷新后可从首页恢复 |
| 主题人生 | 从 0 岁开始；6、11、14 岁均为家庭事件；18 岁出现“出去/留下/谈照护方案”的家庭取舍 |
| 剧本人生 | 九十年代《南下的第 37 小时》第一幕 20 岁、深圳、钩子“身份证被揣进口袋”，三个选项均可选 |
| ForU | 29 岁、上海、产品经理；第一幕裁员场景明确写“你二十九岁”；选择后推进到 31 岁，模式保持 |
| 历史 | 列表出现“ForU 人生”“普通人生”角标；详情出现模式、情境、城市、年龄、节点数 |
| 音乐 | 默认开；关闭后 `localStorage` 为 `off`，刷新仍关；再次打开恢复 `on`；事件页 compact 按钮 44px |
| ForU 校验 | 处境少于 10 字时显示行内错误，不打开性别弹窗、不发起请求 |

## 说明

- 普通、主题、剧本、ForU 的事件均为本地真实模型生成。
- 回顾页为了验证模式化布局，浏览器中临时拦截 `/next` 与 `/ending`，返回固定 ending；没有为截图额外消耗一整局模型调用。真实 ending 的提示词与解析逻辑由 `lib/model-adapter.test.ts` 覆盖。
- 截图只包含游戏界面，不含 API Key、模型配置或 `.data/` 内容。
