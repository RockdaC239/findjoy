# 产品展示页设计简报（showcase-page）

## 目标
明天会场大屏展示用的产品海报页：二维码醒目放大、方便观众扫码；空白区域用产品设计文档中的价值主张填充；整体高级、安静、克制。

## 目标设备
- 主场景：会场大屏 / 投影（16:9，1920×1080 起步，可能 4K）
- 兜底：笔记本、平板、手机（二维码优先、不破版）

## 设计方向
沿用现有品牌系统（paper / ink / orange，DM Sans + DM Serif Display，句点品牌锚点）：
- 整页海报式：细线外框 + 大量留白 + 发丝分隔线
- 左文案 / 右二维码的两栏 16:9 构图；二维码是视觉主角（约 42vh）
- 二维码卡片：白底 + 墨色描边 + 柔和投影 + 缓慢呼吸光晕提示可扫
- 文案取材自《人生模拟器 MVP 产品开发文档 v0.1》：
  - 主标题：人生没有答案，只有选择
  - 价值段落：AI 驱动、不评价成功、不算幸福分数、得到的是一面镜子
  - 三支柱：出生 / 选择 / 回望（对应核心循环）
  - 金句引用：产品宪法（刷属性 vs 想怎么活）
  - 页脚：故事优先于数值 · 不设幸福分数 · 系统负责描述人生，玩家负责评价人生
