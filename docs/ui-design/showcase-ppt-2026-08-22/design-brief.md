# 展示页 PPT 化设计简报（showcase-ppt）

## 背景与目标
会场大屏/投影展示用的产品海报页（app/showcase）目前是单页海报（左文案 + 右二维码）。
本次改造目标：
1. 把 showcase 页改造成「PPT 式逐页演示」（全屏幻灯片 + 键盘/点击翻页 + 页码进度）。
2. 用户提供的产品叙事按演讲需要处理：第 1 页浓缩为要点（去掉第一人称，起提词作用），其余按用户要求精简/合并/删除，**保留的原文逐字不改**。
3. 现有的二维码海报页保留为**结尾页**（第 11 页），继续承担扫码转化职责。
4. 每页配一张来自网络的高质量配图（Wikimedia Commons 自由许可图片，下载到仓库本地，不热链）。

## 目标设备
- 主场景：会场大屏 / 投影（16:9，1920×1080 起步）
- 兜底：笔记本、平板、手机（逐页可翻、文字不破版）

## 设计方向
沿用品牌系统（paper / ink / orange，DM Sans + DM Serif Display，句点锚点）：
- 每页 100svh 全屏、暗底全幅图 + 墨色渐变遮罩，文字压图左对齐（方向 B 全幅沉浸）
- 叙事文案为用户原文整段，按长度分级字号（短句大、长段小），不加标题/加粗/改写
- 配图统一处理成暖调黑白（CSS filter 去饱和 + 轻微暖色）
- 翻页交互：方向键 / 空格 / 点击 / 滚轮 / 触屏滑动；仅手动翻页（用户已确认）
- 结尾页 = 现有二维码海报（"人生没有答案，只有选择" + 扫码开始），原样保留
- 页面路由保持 app/showcase，不改动主流程页面
