# 产品需求（showcase-ppt）

## 用户故事
- 作为会场参观者，我能在展示页上逐页看到 findjoy 的产品理念故事（文案与作者原文一致），被最后一页的二维码吸引扫码体验。
- 作为演示者，我能用键盘/点击流畅翻页，控制演示节奏。

## 功能需求
1. 幻灯片容器：全屏（100svh）、16:9 优先适配、禁用原生滚动（内容以页为单位）。
2. 共 11 页：10 页叙事（用户原文逐字照搬、每段一页）+ 1 页结尾（现有二维码海报页原样保留）。
3. 翻页控制：键盘（←/→/空格/PageUp/PageDown/Home/End）、点击左右半屏、滚轮（节流防连跳）、触屏滑动。
4. 底部 HUD：页码（当前/总数）、进度条、方向提示；结尾页自动切换墨色系。
5. 过渡动画：页面 fade + 文字 rise；prefers-reduced-motion 关闭动画。
6. 配图：每张叙事页 1 张本地图片（public/deck/），统一暖调黑白，加载失败优雅降级。
7. 响应式：1920×1080 大屏、1366×768 笔记本、390×844 手机、280×653 极窄屏均不破版。
8. 无障碍：region 语义、aria-label、aria-live 页码、progressbar 语义。

## 验收标准
- /findjoy/showcase 打开即进入第 1 页，最后一页与现有海报页视觉一致（含二维码）。
- 10 段叙事文案与用户原文逐字一致（自动化断言页面渲染文本 === 原文）。
- 键盘/点击/滚轮均可翻页，页码与进度条正确。
- 各断点截图无溢出、无遮挡、文字完整。
- npm run build / typecheck / lint 通过。

## 不做
- 不改动主流程（开始页/人生页/回顾页）的任何内容。
- 不引入新依赖（纯 CSS + React 实现）。
