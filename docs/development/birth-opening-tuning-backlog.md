## A. 已发现但未改的问题

### A1. 家庭经济与出生地点独立抽样

- 现状：`rollBackground` 先按全国统一权重抽经济，`rollBirthProfile` 再独立抽省市县；地点不影响经济概率。
- 结果：乡村富裕率与城区接近。50轮样本中，城区富裕+大富 8/27（约30%），乡村富裕 3/9（约33%，不含大富）。
- 观感问题：乡村富裕本身可以成立，但程序没有生成“财富来源/地方产业”；城区普通也可能出现收入带4的个体经营者。
- 相关例子：内蒙古兴安盟科尔沁右翼前旗·乡村·富裕，母亲为船舶轮机人员；辽宁营口站前区·城区·普通，父亲为电商企业经营者（收入带4）。
- 待决策：是否引入“地方经济先验/资产来源”，以及经济标签与父母收入带是否双向约束。

### A2. 职业收入带与经济标签只做了单向约束

- 现状：富裕/大富会把低于收入带3的职业抬到3以上；拮据/普通没有反向限制。
- 结果：拮据家庭可出现收入带3的职业；普通家庭可出现收入带4的个体经营；富裕家庭也可能是两名受雇技术岗，靠“家庭资产”解释。
- 待决策：拮据/普通是否限制高收入带；富裕/大富是否更偏向经营/资产型职业，而不是强制高薪岗位。

### A3. 学历完成时间与兄姐年龄没有建模

- 现状：只校验“兄姐出生时父母至少18岁”和“父母出生时年龄不低于学历最低值”，没有校验“父母在完成学历前生育”。
- 结果：出现“24岁大专、兄姐5岁和4岁”“28岁研究生、兄姐4岁和2岁”等需要“先育后学/非全日制”解释的组合。
- 待决策：加严年龄/兄姐规则，或在档案中明确写“学历完成较晚/非全日制”，不把解释留给模型。

### A4. 再婚家庭的兄姐归属未记录

- 现状：`household.siblings` 只有年龄，没有“同父同母/同母异父/同父异母/继兄弟姐妹/养兄弟姐妹”。
- 结果：模型可能把继父/继母写成兄姐的生父/生母，或把兄姐写成同住父母共同的孩子。
- 待决策：兄姐改为对象数组，至少包含年龄与关系；或明确禁止模型推断血缘。

### A5. 城乡 `settlement` 是行政区后缀启发式

- 现状：区名多判城区，县/旗偏向县城/乡镇/乡村；港澳台部分区划也按后缀判断。
- 结果：香港西貢區被标为城区，父母为林场养护工/果园经营者；台湾石碇區也会被标为城区。
- 待决策：接受“区名不等于建成区”的解释，或为港澳台/大城市郊区单独补数据。

### A6. 报告可扫读性

- 现状：50条逐条展开约271KB；汇总 JSON 不适合快速扫读。
- 建议：在汇总 JSON 下面增加一张50行总表（序号、省/市/县、城乡、经济、结构、父母职业、兄姐、事件基调），详情保留在下方。
- 状态：未改。

## B. 新一轮产品反馈

### B1. 适度提高富裕概率，但不能压过普通/以下

- 现状权重：拮据12%、普通38%、小康32%、富裕14%、大富4%；富裕+大富18%。
- 50轮实际：拮据6、普通21、小康10、富裕9、大富4；富裕+大富13/50（26%），已是偏高的一次抽样。
- 反馈：用户如果总抽到一般或拮据，可能失去继续玩的欲望；可以适度提高富裕机会，但仍应是少数。
- 待确认：“普通以下”指
  - 拮据+普通（当前50%），还是
  - 仅普通（当前38%）。
- 可选方案（仅提案，未实施）：
  - 拮据10、普通35、小康30、富裕20、大富5：富裕+大富25%，拮据+普通45%，仍低于普通/以下。
  - 拮据8、普通34、小康30、富裕23、大富5：富裕+大富28%，更积极，但离“真实稀缺”更远。
- 注意：50轮样本波动很大，当前26%并不等于权重18%失效；改权重后仍需用固定种子重跑对照。

### B2. 稀有“极好开局”：富二代/官二代

- 现状：只有经济维度；`大富` 4%，没有“社会资本/家庭资源类型”。50轮大富4例，其中两例父母是受雇技术岗/大学讲师，靠“家庭资产”解释。
- 反馈：希望有极好开局，但必须小概率，抽到能让用户激动。
- 产品拆解建议：
  - “富裕”不等于“极好开局”：富裕20%可以是小康以上的宽裕生活；真正的“极好”应是大富/高社会资本的稀有组合。
  - “富二代”：`大富` + 至少一位父母经营/家族资产 + 家庭资源描述；约3%～5%。
  - “官二代”：建议产品语言改为“体制内家庭/公共资源家庭”，用公共部门、事业单位、地方声望等表达；不宜写成特权/腐败，也不承诺自动成功。约1%～2%。
  - 两者重叠（既富又有体制资源）应更稀有，约0.5%～1%。
  - 极好开局合计建议控制在3%～5%，不要和“富裕25%”混为一谈。
- 需要新增的模型维度（未实施）：
  - `familyFortune`: `普通/富裕家庭/家族企业/体制内资源` 等；
  - 或在现有 `BirthProfile` 增加 `capital` 字段，并同步校验、持久化、近期避重、提示词与报告。
- 敏感点：
  - “官二代”容易滑向特权叙事；需要明确“资源与约束并存”，不把权力写成可继承的外挂。
  - 产品原则是不设统一幸福/成功分数；“极好开局”应理解为资源多、选择多，而不是自动赢。
  - 模型不能因家庭资源就预定主角性格、能力或成年职业。

### B3. 地点权重：主流城市 > 非主流城市 > 自治区/边远

- 现状：
  - 34个省级条目等权；
  - 省内城市等权；
  - 城市内区县等权；
  - 近期6局省代码硬排除。
- 结果：主流城市被稀释。50轮中北京3、上海2、天津2、重庆1、东莞1；广州/深圳/杭州/成都/武汉/南京/西安/苏州均未出现。自治区样本9/50（18%）。
- 反馈：主流城市概率高一点，其次非主流城市，再次自治区。
- 需要先定义“主流城市”。建议用城市层级，而不是简单按“自治区”一刀切：
  - S层（约3～4倍）：北京、上海、广州、深圳；
  - A层（约2倍）：成都、杭州、重庆、武汉、南京、西安、苏州、天津、长沙、郑州、青岛、宁波、东莞、佛山、合肥、济南、福州、厦门、昆明、沈阳、大连等；
  - B层（约1倍）：其他地级市/省会；
  - C层（约0.4～0.6倍）：自治州、边远地区、非主流县级市。
- 注意：自治区内也有主流城市（乌鲁木齐、南宁、呼和浩特、银川、拉萨）。如果按“自治区”整体降权，会误伤这些城市；更合理的是“城市层级 + 自治区内非主流地区降权”。
- 目标分布建议（仅提案）：
  - S+A 主流城市 40%～45%；
  - B 非主流城市 40%～45%；
  - C 自治区/边远 10%～15%。
  - 当前50轮约为：主流城市10/50（20%）、二线/普通地级市9/50（18%）、其他31/50（62%）、自治区9/50（18%）。主流明显偏低，C层偏高。
- 另一个隐藏原因：`sampleBirthLocation` 对最近6个省份做硬排除。北京/上海等主流省份一旦在最近6局出现，就会被排除6局；这会让主流省份更难重复出现。建议改软降权，或只避最近2～3局，且只避具体城市而不是整个省。
- 城乡比例：主流城市提高后，城区比例会自然上升；但仍应保留乡村/县城样本（建议乡村+乡镇不低于25%～30%），否则“普通人生”会变成城市中产模拟器。
