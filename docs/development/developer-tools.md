# 个人开发调试工具

2026-11-03，开发分支实现，未发布。此工具只服务当前 Owner 的开发需要，不建立通用管理员系统，不改变跨产品身份或权益约定。

## 入口与权限

首页左上 Logo 连续点击三次（相邻点击间隔小于 800ms），服务端验证当前登录账号的已验证手机号为指定 Owner 号码后，弹窗选择「进入调试模式」或「进入 Showcase」。普通点击不再直接跳转 Showcase。

权限源是 `identity_users.phone`，该字段由现有 OIDC 已验证手机号逻辑保存。兼容国内号码和 +86/0086 前缀；不从昵称、前端参数、localStorage 或客户端布尔值判定权限。缺少已验证手机号时拒绝。权限检查集中在 `lib/developer.ts`，原 Showcase 展示页面本身保持现状。

## 节点预览

`/developer` 服务端再次验证权限。可选择出生与早年、童年、成年选择、生成中、告别与回顾、等待回顾、回顾失败、人生回顾。可重新播放；成年选项只反馈点击结果，不推进真实存档。

预览使用合成资料，复用实际 `LifeEventScene`、`Farewell`、`ReviewExperience`、`ReviewView`。不会调用模型、扣积分或修改真实人生；回顾通过合成内容注入，等待与失败可单独查看。

## 给自己增加积分

调试页按钮每次增加 1000 积分，只能发给当前登录的开发账号。接口检查同源、权限、幂等键与每分钟最多5次的限流，更新账户与 `developer_grant` 账本记录在同一事务内进行，沿用余额锁。

前端不提交用户ID或积分数量。网络结果不确定时重试沿用原幂等键，不重复发放。浏览器刷新后余额由服务端重新读取；该积分是本产品业务积分，不是另一个钱包。

## 一分钱测试套餐

Owner 账号的充值页额外展示「开发者测试支付」：¥0.01、20积分。普通用户不可见，也无法通过构造下单请求获得。结算页、订单创建及支付重试各自验证权限；金额与积分从服务端商品目录确定，不接受客户端报价。正式商品配置不能占用保留ID `developer-test`。

沿用现有微信支付、验签、金额核对、回调幂等与到账逻辑。`FINDJOY_PAYMENTS_MODE=demo` 时仅演示，不收款、不发购买积分；live 时才发起真实一分钱支付。本次没有切换生产支付配置、创建真实支付订单或发布。
