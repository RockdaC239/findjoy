## 本轮程序规则

- 城市层级先加权：S 16%、A 32%、B 42%、C 10%；再在层内按真实城市抽，自治区首府仍在 A/B 层，不按“自治区”整体一刀切。抽样是编辑探索分布，不是人口统计。
- 家庭经济基础权重：拮据10、普通35、小康30、富裕20、大富5；再按城乡做轻度先验（城区富裕更高、乡村更低）。总体富裕+大富仍低于拮据+普通。
- 稀有开局与普通富裕分开：`capital.golden` 为 `富二代` 或 `官二代`，合计约6.7%。富二代只在大富层按30%抽取，并强制至少一位父母个体经营；官二代在小康/富裕层按10%、大富层按4%抽取，并强制一位父母在公共事务/政策研究岗位。极好开局不等于自动成功，提示词明确资源、约束与家庭期待。
- 父母学历决定可任职资格，优先匹配同档或低一档岗位；同一家庭内先避开已抽到的父母职业。研究生不会被默认安排成义务教育岗位。
- 父母出生时年龄按学历设置最低值（义务教育20、高中/中职22、大专/本科24、研究生27；养父母28），并校验兄姐出生时父母至少18岁。
- 兄姐数量按城乡加权（城区78/19/3、县城65/29/6、乡镇55/36/9、乡村45/40/15），避免把“两个兄姐”的三孩家庭当成常见默认。
- 家庭经济只生成住房、照护、通勤、支持、开支压力与资源描述；资产不等于主角个人资源。父母角色/状态/职业是出生时事实，不据此预定主角性格、天赋或成年职业。
- 出生档案写入 `LifeState.birth`，旧存档可缺省；迁居只改 `basic.city`，不改出生地。恢复存档时会重新校验出生档案，损坏字段不进入提示词。
- 普通/主题开局不再使用旧“生活机会环境”，避免与具体出生地/家庭条件冲突；旧存档仍兼容读取。
- 城区不再生成农林渔业职业，避免“北京东城粮食种植户/香港果园经营者”这类地理冲突；乡村/县城保留农业机会。
- 有出生档案时，系统提示词使用【程序出生事实】+【本局开局事件基调】；“家庭变故”不再默认写父母分开或亲人离去，开局不改写同住/缺席状态。
- 近期避重采用软降权而非硬过滤：最近用过的出身取值降低概率，但不把少数派全部排除，避免连续六局覆盖少数派后把家庭结构压成单值。

## 已知限制

- 权重为编辑探索权重，未经统计校准；50轮 dry run 不能证明长期剧情多样性或真实出生分布。本轮富裕+大富30%与普通单项30%持平，正好落在“不能超过普通”的边界，真实长期分布仍需更大样本。
- 本轮没有调用 LLM，不能评价模型是否遵守出生事实、是否把富二代/官二代写成特权爽文；需要 Owner 确认后的真实调用验证。
- 城市层级名单是编辑选择，不是人口/经济统计；S/A/B/C 的划分和比例需要 Owner 确认。
- 经济与地点只做了“城乡轻度先验”，还没有省/市经济先验；同一城市层级内的富裕率仍相同，也没有地方产业来源。
- 城乡 `settlement` 目前按行政区名称后缀启发式判断（如“区”多为城区），不按实际建成区/人口密度；部分城市郊区、港澳台区划会被标为城区。
- 父母年龄最低值只约束出生时年龄；兄姐可能与父母取得学历的时间重叠（例如先有孩子、后完成学历），不视为非法档案。
- 拮据家庭仍沿用既有 `debt` 初始值；出生指令要求不补造具体债务原因，但报告中的债务数额本身尚未与新的家庭资源模型进一步对齐。
- 再婚家庭的兄姐仍只记录年龄，没有记录“同父同母/同母异父/继兄弟姐妹”等关系。

地域完整性、资料版本与港澳台覆盖以实际数据审查记录为准，不用不存在的行政区凑数量。测试使用独立本地 PG15 实例。模拟使用合成资料，禁止包含真实用户自述、会话或密钥。
