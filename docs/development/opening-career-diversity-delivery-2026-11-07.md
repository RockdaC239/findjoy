# 开局与职业多样性修复交付记录（2026-11-07）

> 执行依据：[开局与职业路径同质化修复方案 v2](./opening-career-diversity-fix-plan-2026-11-07.md)。
> 范围：普通模式开局与职业识别；未改 UI、计费、登录、持久化架构，未发布生产，未提交 Git。

## 1. 结论

- 开局骨架撞车已从“多数局”降到 **0/20**：“大人发现手巧 → 送旧工具 → 学手艺/接活”在最终 20 局里一次完整组合都没有出现，也没有出现“你手稳/你手巧/师傅/学徒/修车铺/擦玻璃”作为开局核心。
- 十五岁出现带报酬的活：**1/20**（快递点分拣），其余 19 局的首个选择都不是接活、打工或选职业。
- 二十局的开局方向覆盖 **11 种机制、9 种主要关系、9 种推动力、8 种代价类型**，同一机制最多出现 3 次。
- 三条后续轨迹分别走到 **电梯维保技术员、变电站运维员、临床医学本科在读**，没有再汇入“中职机电 → 师傅 → 接店”这一条老路。
- 仍有 1 局把“帮亲戚看摊”写成带工资的活，4/20 的“实际机制”与抽中方向只是松散对应；这些属于编辑级问题，已在第 6 节列出。

## 2. 改动清单

### 2.1 职业域识别（`lib/storyline.ts`）

- 新增 `construction`（建筑规划）、`manufacturing`（生产制造）、`repair`（维修技工）三个域；`government` 补入消防/救援。
- 职业域**只从 `career.occupation` 与 `objectiveChanges.occupation` 提取**，不再读事件标题。标题里的“老师问你去不去云南调研”“父亲让你暑假去工地画图”不再把主角误判成教育/建筑。
- 已退休/已离职的人生仍能提取历史职业主线；从没建立过职业的童年人生仍返回空。

### 2.2 教育分流边界（`lib/engine/event-facts.ts`）

- 用“教育阶段序号”替代关键词白名单：中职/技校/职高、专科/高职、本科、硕士、博士属于分流点，跨层级进入需要 `lifeChanges` 含 `education`。
- 初中→高中放行（义务教育后的常规延续），小学直接跳高中仍拦；`未开始` 视为“还没填过”，第一次写入当前学历不拦。
- 真实回归样本：a17ec 的“初中在读 → 中职在读，机电技术应用专业，lifeChanges=[]”现在会被拒绝；“高中毕业，考入省城院校机械专业”这类复合字符串也能识别。

### 2.3 开局方向采样（新增 `lib/opening-plan.ts` + `lib/engine/prompts/opening-plan.json`）

- 四个维度：主要关系 × 推动力 × 故事机制 × 代价类型。代价单独成维，因为真实样本里模型总把“给你多少钱”当成唯一具体的代价。
- 目录权重：“发现特长”“家庭安排”“钱与开销”降权；其余机制、代价权重相当。
- 近期同一 id 权重降到 0.15（不硬排除）；四元组与最近几局完全相同时有限次重抽。计划里存最近 4 组组合，供开局提示词说明“最近用过什么”。
- 抽样在 `resolveStartPlan` 完成，随 `createStartLife` 写进 `state.openingPlan`；同一幂等请求、模型重试、刷新恢复都复用同一份，不重新抽。
- `app/api/life/start/route.ts` 传入当前用户的 `recentOpeningPlans(6)`；Mock 开局不抽样、不写计划。

### 2.4 近期样本与用户隔离（`lib/life-store.ts`）

- 新增 `recentOpeningPlans`：按 `updated_at` 取最近 6 局、按用户过滤、跳过 `flags.developerMock === true`、跳过没有计划的老存档，不读全文、不调用模型。
- `get()` 读档时用目录校验 `openingPlan`，未知 id 直接丢弃，不进入提示词。

### 2.5 提示词组装（`lib/engine/prompts/assemble.ts`、`lib/engine/context.ts`）

- 开局方向只在 `mode === "normal"` 且本轮是开局（或开篇恢复）时追加，放在 `opening.md` 之后。
- 后续轮次、主题、剧本、ForU、旧存档都不会出现这段；`buildBirthDirective` 未改动，避免每轮污染。

### 2.6 开篇写作指令（`lib/engine/prompts/opening.md`）

- 取消“第一段/第二段/第三段/第四段各写什么”，改成 2～3 个场面、320～450 字、顺序不固定。
- 增加反面样例：不要每局都写“手巧 → 旧工具 → 学手艺”；不要写“你手稳/你手巧”；父母的职业不要自动变成孩子的天赋。
- 增加：十五岁的孩子可以帮忙，但不写成雇佣；不写工钱、分成、一个月多少、管吃住给零花；帮忙的代价是人情、时间、机会或一句难说的话。
- 增加：三个选项必须是三种行动方向，不能是“接受/拒绝/先试试/再商量”。

### 2.7 通用选择规则（`lib/engine/prompts/two-scene.md`）

- 在“高中到大学、学生到正式工作之前要给玩家选择”后补一句：初中毕业同样要把普高、中职、技校或就业的去向交给玩家选择。

### 5.3 代表性开局（匿名摘要）

1. `grandparent / curiosity / farewell / loss`，甘孜乡镇：童年跟外婆约定“长大带你看海”，十五岁外婆腿脚不行、家里要送养老院；第一个选择是“买车票赶在登记前带她走 / 填表先看环境 / 跟母亲摊牌”。
2. `neighbor / environment-change / loyalty / face`，宿迁乡镇：街坊二姐要借院子堆货，父亲让“你说了算”；选择是借、不借、还是讲条件。
3. `parents-work / institution / mistake / trust`，焦作乡村：母亲把“我爸总不在家”改成“我爸守护万家灯火”，让主角在单位开放日上台念；选择是照念、念自己的、还是把两段都摊给母亲。
4. `school / family-arrangement / secret / loyalty`，南昌乡村：哥哥的处分通知被班主任拿出来，哥哥求“别跟爸妈讲”；选择是告诉老师、说不知道、还是先让哥哥自己决定。
5. `self / money / promise / trust`，贵港乡村：膝盖疼，却答应陪同桌跑完三千米；选择是说清、硬跑、还是先去问体育老师。

这五局的共同点是：十五岁的处境不再是“有人给你一份活”，代价也不是“给你多少钱”，而是面子、承诺、站边、信任和时间。

## 6. 仍未解决 / 需要 Owner 试玩

1. **十五岁仍有 1/20 带报酬的活**（快递点分拣）。提示词已明确禁止，但没有做关键词硬拦截；如果试玩仍觉得刺眼，下一步可以只在开局事件上做一次窄范围重试，而不是全文审查。
2. **4/20 的“实际机制”与抽中方向只是松散对应**（例如抽到“搞砸之后收拾”，写成“被同学连累”）。没有做运行时一致性校验，靠编辑审读。
3. **选项仍常出现“接受/拒绝/先问问”的三段式**，虽然已要求三种行动方向；这是模型习惯，需要继续用真实样本压。
4. **既有职业授权校验会连续三次拒绝后停止本轮**（本轮 35 幕续玩里出现 3 次，玩家重试 2 次后恢复）。这是上一轮就有的行为，不是本轮引入；生产表现是“本轮不推进，可重试”。
5. 三个选项里的“折中/先问清楚”仍偏多；`discovery`（发现特长）仍是权重最高的“低权重项”之一，最终 20 局出现 2 次。
6. 情绪与文风已比修复前分散（尴尬、难堪、告别、默契、内疚都出现），但“像不像一个有记忆点的人”仍需 Owner 连续试玩判断。
7. 计划文档里提到的“近 12 局 4 局上海”现象没有复现出采样器缺陷：单独跑 4 万次，避让后上海从 4.19% 降到 2.45%，说明软权重是生效的；那几局很可能来自早期进程或不同构建。没有为此改采样权重。
