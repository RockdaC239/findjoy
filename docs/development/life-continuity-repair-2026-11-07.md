# 人生连续性修复与验证（2026-11-07）

## 目标与范围

在已有 v3 两幕体验上，修复近期完整试玩暴露的数值、时序、选择权限、记忆和终点问题，并拓展生活与情绪。开发在 test 分支，不迁移玩家历史，不发布生产，不改 UI、登录、计费或持久化架构。

## 实现

- 新生成必须提供 timeline（resultAge/sceneAge）、stateUpdate、lifeChanges；选项包含 requiresFollowUp 与 commitments。生成入口与保存入口校验，旧事件仍按原协议读取。
- 现金 received/paid、借还款 borrowed/repaid 都为有限非负数；资产和健康是当前值，程序转换成现有 objectiveChanges 增量。拒绝超额支出、超额还款、混用增量、非有限值与不安全余额；借还款同时记现金流。转录保留新事实格式，不把已经转换的增量冒充新协议。
- 选择授权涵盖婚恋、婚姻、生育、住房、升学和职业。只有所选行动明确授权的承诺才能成立；明确授权和对应客观变化已经齐备时，可补全冗余标签。无法从后台字段识别所有隐含决定，因此同时加强生成规则与人工样本审读。
- 试行的去留未决时同龄交回选择；同龄结果年龄缺省可唯一确定为当前年龄，跨年结果年龄不能猜。场景年龄必须等于原年龄加跨度，结果年龄在本轮范围内。该结构校验不能证明每个自然语言时间描述都正确。
- 针对明确的第二人称领证、配偶、子女断言补窄范围一致性检查，排除引号内问话、他人婚事，允许已有婚姻/子女的状态变化与回忆；不把正则当成全文语义审查。
- 提供允许落地范围、各落地年龄的亲属年龄及保存的生死状态；处理描述式死亡状态，去除已故父母的活跃记录；终点清空待操作方向和事项，历史中的遗憾仍保留。
- 在可达终点的轮次提前要求完整终幕。v3 到上限仍返回 continue 时重试，不再追加模板死亡。耗尽重试不推进；保留 v2 旧流程兼容。
- 每轮观察最近六幕的内容和题材，普通人生明显收窄在工作经营或照护健康时加强拓展生活提醒，避开试行未决与终点，保留主题/剧本情境。清理“每个场面必须对立”“每幕必须续旧账”等与舒缓生活冲突的规则。
- 重试提供最新具体失败原因与上一份原稿，使模型纠正同一稿；原稿仅在请求内存中，不新增玩家内容日志。可无歧义规范化的承诺标签格式不额外重试。

## 回归覆盖

包括还款归零、健康当前值、入股现金方向、负数/超额/溢出、别名与嵌套更新、保存边界的数值一致性、同龄试行、未授权升学毕业/职业转换/婚育、已有婚姻条件变化、描述式亲属死亡、终点拒绝继续事件与正确纠正重试。请求与转录、普通/主题/剧本/ForU 的原测试继续运行。

## 真实模型验证方法

使用本地模型配置与合成出身，通过实际 streamNextEvent、请求转录、规范化及 applyNextEvent 跑完整人生。没有发送玩家存档，没有写业务库或扣玩家积分。调试失败稿和生成样本位于 Git 忽略的 `.data/life-repair-validation*`；不同轮次用于比较定位，不混作同一版本的成功样本。

完整样本按固定种子创建三种出身，依次轮选选项，不按“正确人生”挑选。若连续三次生成被拒绝，保存状态不变；测试可模拟用户对同一选择再次请求，必须记录这类失败，不能把它算成一次无重试成功。主题、剧本、ForU 各检查开场与后续，另用缺少新协议字段的合成旧存档续玩。

本地配置没有给 deepseek-flash 配置有效计价，usage 的 estimatedCostUsd=0 不代表免费。记录真实 tokens、缓存、调用次数与延迟；不据此编造费用估算。

## 限制与验收边界

程序可保证数值协议、明确的权限与年龄范围、重试不推进和终点格式，不能保证每句自然语言都与字段一致，也不能自动证明情绪有电影般的感染力。实际样本仍需逐幕审读，Owner 连续试玩是叙事验收的一部分。已保存的错误数值、年龄与历史文本不会被本次修复回写。


## 最终样本与观测

最终审读集为 `.data/life-repair-validation-final-r6`。三条合成普通人生分别为28幕/73岁、18幕/82岁、17幕/74岁。完整轨迹经过真实模型生成；调试中被拒绝的节点保持原状态，修复后按同一选择续跑。最后两条终幕使用已捕获、未经改写的真实模型原稿，经当前规范化、生命周期校验、保存断言与状态应用回放；一条终幕由当前生成入口直接完成。所有轨迹逐幕重新验证，终点人物、方向、待办均为空。不能把这些过程称为三局从头到尾一次生成成功。

61个有完整usage记录的接纳节点共2,954,783 tokens，接纳节点平均生成约7.5秒、最长约17秒，包含其内部纠正重试。两条终幕原稿回放没有对应最终接纳usage，完整失败请求及前期调参调用也不包含在这个合计内；不据此宣称全部实验费用或耗时。严格校验可能使一次请求连续三次失败，实际样本中确实发生过；生产行为是本轮不推进、允许重试，不伪造剧情绕过。

样本中出现了球局、朋友邀约、湖边相遇、社区手工班、书店等工作之外的场景，以及试行后回到去留决定、亲人相处和旧物回响。仍有任务型取舍与局部自然语言时序/亲属年龄偏差；程序不具备全文语义证明能力，Owner连续试玩仍是叙事验收。主题/剧本/ForU各3幕、旧格式存档2幕的真实模型续玩也已完成；它们不是这几种模式的完整寿命质量保证。

终幕专属指令在 `prompts/terminal.md`，进入最后阶段后程序既拒绝普通事件，也拒绝通过缩短跨度继续出题。缺失且应为空的story/choices可以补为空；没有给死因时保留“其他/未详”，不推断疾病。明确死亡后允许一两句旧物收尾，不强制生成模板死亡句。出生档案的同住/异地不再伪装成当前亲属生死状态，未知时不填。
