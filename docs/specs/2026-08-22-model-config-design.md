# 模型配置双模式设计

## 目标

开源用户在本地运行 FindJoy 时，可以通过右上角设置配置供应商、API Key 和模型，并将配置保存到本地文件；线上部署继续由维护者通过环境变量锁定模型配置，不接受浏览器传入的自定义模型。

## 方案

本地模式使用 `.data/model-config.json` 作为服务端配置文件。设置面板提交到本地 API，由服务端校验供应商和模型后写入文件；API Key 只在服务端读取，不返回给浏览器。`.data/` 已被 Git 忽略，因此不会进入开源仓库。

线上模式由 `FINDJOY_MODEL_CONFIG_MODE=environment` 或生产环境默认启用。服务端只读取 `LLM_*` / `OPENAI_*` 环境变量，并忽略请求体中的 `modelConfig`。前端设置面板展示线上锁定提示，不允许编辑。

本地模式判定为显式 `FINDJOY_MODEL_CONFIG_MODE=local`，开发环境默认本地模式；生产环境即使未设置模式也默认环境变量模式，避免误开放配置写接口。

配置优先级：线上环境变量；本地配置文件；环境变量默认配置。缺少 API Key 时返回清晰错误，不把 Key 写入 lifeStore、日志或响应。

## 验收标准

- 本地设置可保存、读取并在后续人生请求中生效。
- 线上请求体自带配置时仍使用服务端环境变量。
- `.data/model-config.json` 不被 Git 跟踪。
- README 包含本地启动、模型配置、线上部署和欢迎 PR 的说明。
