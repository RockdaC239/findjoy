## 提取结论

手机端有独立的触控、阅读、安全区、弹窗、软键盘和购买布局规则；平板单独保留阅读尺度；showcase 含窄幅手机端任务样例，不能只看桌面组件排列。当前运行平台仍为响应式 Web，不宣称已有原生客户端。

主题是「纸页上的人生」，而非经营数据后台。以纸白、墨黑和橙色为主线；内容领先、数字服务故事。细描边与空白比阴影承担更多层次。文案可以有温度，但任务区域不堆口号。

本轮提取不为 FindFire 指定视觉或架构，也不变更跨产品契约。

## 原品牌页的保留与纳入

`app/brand/page.tsx` 原文件保留，`/findjoy/brand` 继续可用；`BrandLogo`、Logo SVG 与 favicon 均保留。DNA 与变体规则纳入 `DESIGN.md` 第 3 节，静态 showcase 复现字标样本。

原页橙底样例 CSS 将句点改为墨色；纸白/墨黑样例保持橙点。这是背景适配的既有变体，不能用“句点永远橙色”机械覆盖。字标句点与页面标题标点分别管理。

## 新的数值入口

原来的六个 `:root` 配色已迁入 `tokens/tokens.json`，由生成的 CSS 提供兼容别名；视觉值保持不变。使用 `npm run design:tokens` 更新 CSS，`npm run design:check` 检查漂移。未来维护者先读 `DESIGN.md`；`app/globals.css` 仍负责现有布局与未迁移样式。

这一轮统一基础值与文档，不宣称全站所有硬编码已经 token 化；尤其原品牌页与演讲页不做批量替换。
